# HF to Ollama

Утилита для Mac с Apple Silicon. Скачивает Safetensors из Hugging Face, импортирует модель в локальный Ollama через MLX и делает короткий проверочный запрос.

## Запуск

Соберите приложение командой ./build.sh и откройте dist/HF to Ollama.app. Для работы запустите Ollama.

## Поддержка

- Gemma 4 26B-A4B MXFP4 в раскладке TheCluster. Утилита объединяет веса экспертов и преобразует 8-битные слои MLP в 4-битный MXFP4. Для маршрутизатора сохраняет деквантованные веса.
- Для других готовых Safetensors-сборок утилита пробует штатный импорт. Для весов без квантования просит Ollama применить MXFP4. Поддержка зависит от архитектуры и формата весов. GGUF в этот процесс не входит.
- Проверка использует текстовый запрос с контекстом 4096 токенов. Изображения, инструменты и длинный контекст этой проверкой не покрываются.

Скачанные веса остаются в `~/Library/Caches/HF to Ollama`. Последующие запуски с тем же репозиторием и ревизией могут использовать уже скачанные файлы. На время обработки протестированной Gemma 4 может понадобиться около 30 ГБ для промежуточных копий, помимо исходных весов и модели в Ollama. Утилита удаляет временные копии по завершении.

## Из Терминала

```bash
python3 backend/import-model.py --repo TheCluster/Gemma-4-26B-A4B-Heretic-MLX-mxfp4 --name gemma4-custom:26b-mlx
```

Можно указать конкретную ревизию через `--revision` или использовать `--local "/путь/к/весам"` вместо `--repo`. Выбирай свободное имя. Если импорт прошёл, а тестовый запуск завершился ошибкой, утилита покажет ошибку Ollama и имя созданной записи.

## Графическое приложение

Нативный интерфейс macOS находится в Sources. Вкладки позволяют импортировать модели, управлять установленными моделями, строить графики тестов и создавать копии с другим квантованием.

Требования — Apple Silicon, Python 3.10+, hf, uv и запущенная Ollama. Для сборки нужны инструменты Xcode со Swift. Разработка проводилась с Ollama 0.40.16. Приложение обращается к localhost:11434. Закрытые репозитории требуют предварительного hf auth login.

Запустите ./build.sh. Приложение и архив появятся в dist. Сборка имеет локальную подпись, нотариализация Apple отсутствует.

## Квантование установленных моделей

Во вкладке «Квантование» выберите модель Ollama, 4 или 8 бит и новое имя. Читаются локальные веса из ~/.ollama/models либо OLLAMA_MODELS. Создаётся отдельная копия. Поддерживаются MLX-модели, GGUF пока не поддерживается. Промежуточные распакованные веса могут занимать десятки гигабайт. Повышение разрядности не восстанавливает утраченную точность. Draft-модель, пользовательские шаблоны и параметры исходной записи автоматически не переносятся.

## Тестирование

Каждая модель выгружается и загружается перед одинаковым текстовым запросом. Контекст 4096, до 128 токенов, два запроса. На графиках показаны load_duration первого запроса, size из Ollama /api/ps в десятичных ГБ и средняя скорость токенов/с. Дисковый кэш macOS влияет на время загрузки. Память модели не равна общей памяти процесса. Качество ответов тестом не оценивается.

Проверены импорт Gemma 4 26B Heretic, преобразование Qwen 9B из 5 в 8 бит, создание 4-битной копии установленной Gemma MLX, тестирование восьми записей Ollama, переименование и удаление временной записи. Универсальная совместимость со всеми архитектурами не гарантируется. Проверка генерации после импорта короткая. Интерфейс и остановка требуют дальнейших сквозных проверок.

## Файлы проекта

Sources содержит Swift-интерфейс. backend содержит Python-загрузчик, преобразователи, тесты и управление Ollama. assets содержит иконку и Info.plist. Веса моделей и пользовательские токены в проект не входят.
